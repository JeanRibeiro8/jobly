## 🚀 About

A learning project for a modern job board built with React and TypeScript.


## Current features

- Job title search
- Location search
- Job type filter
- Responsive layout
- Empty state
- Typed job data
- Component-based React structure

## Planned features

- REST API integration
- Loading state
- Error state
- Pagination
- Job details page
- Forms
- Improved API/data handling

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
